# ops-proxy (مؤقت)

واجهة تنفيذ قصيرة الأجل لتمهيد النسخ الاحتياطي والترحيل وحيد الاستخدام عبر
شبكة Blitz (قاعدة البيانات لا تقبل اتصالات من خارج الشبكة الخاصة).

- المصادقة متطلب صارم عبر `Authorization: Bearer $OPS_PROXY_TOKEN`.
- `DATABASE_URL` يُحقن من خدمة Blitz المرتبطة، ولا تخزن أي قيم سرية في هذا المجلد.
- بعد اكتمال الترحيل يُحذف التطبيق والحلقة من الحساب، ثم يُنزع هذا المجلد من الفرع.

نقاط الوصول:
- `GET /healthz` فحص الاتصال.
- `GET /tables` جرد الجداول والعدد.
- `GET /backup` تفريغ كامل قابل للاستعادة (SQL نصي).
- `POST /exec` تنفيذ SQL بصيغة JSON معاملةً واحدة (يعمل داخل معاملة) —
  متاح فقط للرمز، ولا يُستخدم بعد انتهاء مرحلة الترحيل.
